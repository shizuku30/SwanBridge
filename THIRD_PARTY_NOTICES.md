The strongSwan checkout is obtained from the pinned archive, not committed as a
binary or an opaque local dependency. `scripts/strongswan-rekey-race.patch`
records the local Child-SA lookup modification. Static plugin constructor
tables are regenerated by the build, not stored as local-only changes.

The Windows build copies `COPYING.strongswan` and the available runtime license
directories into the package. `licenses/` in the build layout contains those
verbatim dependency notices. Package versions can differ when MSYS2 updates its
repositories; keep a package inventory with any distributed binary and obtain
the corresponding dependency sources before release.

No commercial VPN code or drivers are included. The Microsoft UWP VPN sample
is a reference, not a vendored or copied dependency. The supplied application
icon is covered by the separate owner authorization in `LICENSING.md`.
